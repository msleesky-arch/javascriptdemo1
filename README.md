# JS Lab — JavaScript 핵심 라이브러리 20선 & 실무 활용 가이드

HTML, CSS, JavaScript와 **20개 대표 라이브러리를 1:1 매칭**하여 제작한 실시간 인터랙티브 플레이그라운드이자 실무 활용 가이드입니다.

---

## 🚀 빠른 시작

1. `index.html` 파일을 더블 클릭하여 브라우저에서 바로 열 수 있습니다.
2. 모든 라이브러리는 `vendor/` 폴더에 오프라인 로컬 번들로 포함되어 있어 별도의 `npm install`이나 인터넷 연결 없이 동작합니다.
3. 로컬 웹 서버 환경에서 열고 싶다면 아래 명령어를 실행하세요:
   ```bash
   python -m http.server 5173
   # 브라우저에서 http://localhost:5173 접속
   ```

## 💡 주요 개선 사항 (v2.0)

1. **라이브러리 1:1 구조 개편**: 중복/분산되어 있던 30개 데모를 20개 라이브러리 각각의 고유한 대표 데모로 1:1 완벽 통합.
2. **언제 쓰면 좋은가? (실무 활용성) 탭 신설**: 모든 라이브러리 모달에 실무 추천 시점, 대표 활용 사례 3가지, 핵심 장점, 실무 꿀팁을 전용 탭으로 제공.
3. **기능 오류 및 UX 개선**:
   - **SweetAlert2**: 모달 다이얼로그 겹침 및 배경 클릭 시 다이얼로그 닫힘 현상 해결.
   - **Canvas Confetti**: 모달창 내부 전용 캔버스 렌더링으로 가림 현상 없이 폭죽 연출.
   - **QRCode.js**: 한글(UTF-8) 입력 시 발생하던 문자열 길이 초과 오류 완벽 해결.
   - **JsBarcode**: 한글 입력 시 친절한 유효성 안내 및 원클릭 샘플 프리셋 제공.
   - **Anime.js & GSAP**: 모달 열림 즉시 자동 재생 및 직관적인 컨트롤 버튼 제공.
   - **SortableJS**: 카드 전체 드래그 지원 및 부드러운 애니메이션 적용.
   - **Chart.js**: 막대, 선, 도넛, 파이 차트 형태 실시간 전환 및 랜덤 데이터 추가 기능 지원.
